Featured project

Applied AI · CSCI933 Group Assignment

A retrieval-augmented Shakespeare tutor

Ask a question about Hamlet, Macbeth, or Romeo and Juliet in plain modern English — get an answer grounded in the actual text, not a guess.

Built as part of my Master's coursework, this system retrieves the most relevant passages from the plays using sentence-transformer embeddings and cosine similarity, with summary-enhanced chunking to bridge modern phrasing and Shakespearean language. A Llama 3.1 8B model, served via the Groq API, then generates the answer from the retrieved text, rather than from memory alone.

I also built a baseline system with no retrieval step, so I could measure — not just assume — how much the retrieval actually improved answer quality, correctness, and grounding. The whole thing runs as a live Streamlit app.
